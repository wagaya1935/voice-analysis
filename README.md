# 卒業研究の一歩

## 概要
「Cevio AI」のOИE(オネ)と「UTAU」の重音テトを使用して、DECO*27さんの[モニタリング(Best Friend Remix) feat. 初音ミク]のサビ部分をカバーした音声を作成して解析してみた。

## 背景
卒業研究で音声合成の音声波形解析を使って、人間にとって心地よい音声があるのか、また心地よい音声がある場合、それらは音声合成を使用したヒット曲も関係性があるのかを研究したいと考えている。

その研究をするため一歩として、今回の波形解析・比較をしてみた。

## データの取得方法
作成したonesong.wavとtetosong.wavをcsvファイルに変換して用いた。

データ形式の違い(サンプリング周波数)

録音する環境が違うため、それぞれが一番自然な周波数に設定している。
  - OИE(オネ)：48kHz
  - 重音テト：44.1kHz

##  手順
1. データのサンプリング周波数fsを確認し、周波数分解能Δfを決め、解析他のため、以下のパラメータを求める。
   - データの数N = fs / Δf
   - ナイキスト周波数fn
   - ウィンドウ幅Tw
2. 波形の形状の比較。
3. 時間窓を決め、高速フーリエ変換を行う。
4. 短時間フーリエ解析を行う。
5. スペクトログラムの比較。
6. フーリエ逆変換を行い、3.の結果が元の波形に戻るかを確認する。

## 気づいたこと
AI音声合成であるOИEは、波形の非周期性やスペクトルの滑らかな減衰といった「人間らしい揺らぎ」を再現していることが確認できた。対して、サンプリング方式であるUTAUの重音テトは、波形の高い規則性や特徴的なスペクトル形状といった「録音音声をつなぎ合わせた連続音」に基づく機械的な特徴が確認できた。
